# Book Service - Система учета книг для сервиса
## Назначение
Система предназначена для учета книг, которые пользователь читает, планирует прочитать или уже прочитал. Помогает отслеживать прогресс чтения и формировать персональный список литературы.
## Целевая аудитория
Любой человек, который хочет отслеживать свои прочитанные книги
## Предметная область
Предметная область — персональный учет книг для чтения. Пользователь ведет список книг, присваивая им статус:
- **Хочу прочитать** — книги, которые планируется прочитать
- **Читаю** — книги, которые читаются в данный момент
- **Прочитано** — завершенные книги
- **Отложено** — книги, чтение которых приостановлено

Система позволяет:
- Добавлять книги с указанием автора, года и статуса
- Просматривать книги по статусам
- Изменять статус книги по мере продвижения чтения
- Удалять книги из списка
## Основные сущности
### Пользователь (User)
- **id**: уникальный идентификатор
- **name**: имя пользователя
- **created_at**: дата регистрации

### Книга (Book)
- **id**: уникальный идентификатор
- **title**: название книги
- **author**: автор книги
- **year**: год издания
- **status**: статус чтения
- **user_id**: идентификатор пользователя

### Список (List)
- **reading** — "Читаю"
- **want_to_read** — "Хочу прочитать"
- **read** — "Прочитано"
- **on_hold** — "Отложено"

### Статус (Status)
- **want_to_read**: книга запланирована к прочтению
- **reading**: книга в процессе чтения
- **read**: книга прочитана
- **on_hold**: чтение приостановлено
## Основные функции
1. **Просмотр всех книг** — отображение полного списка с информацией
2. **Просмотр по статусам** — фильтрация книг по статусу (хочу прочитать / читаю / прочитано)
3. **Добавление книги** — внесение новой книги в систему с указанием статуса
4. **Изменение статуса** — обновление статуса книги (например, "хочу прочитать" → "читаю" → "прочитано")
5. **Удаление книги** — удаление книги из списка
